# PRD 补充：项目来源与许可检查

本文件补充 [Mac Teleprompter PRD v1.0](../public/assets/aistudio/Mac_Teleprompter_PRD_v1.0_40f1ece4.pdf) 的发布要求，不修改或替换原 PDF，也不改变本项目自身代码的许可。

## 当前实现与原计划

原 PRD 的实现方向是基于 [pedrambayat/teleprompter](https://github.com/pedrambayat/teleprompter) 的 macOS 原生项目进行改造。当前仓库则采用 React、TypeScript 和 Vite，实现浏览器版环绕提词器。

本次检查没有确认当前 Web 实现是否复制、移植或改编了该上游的代码或其他受保护材料。技术栈不同不等于没有复用；功能相似或曾计划参考上游，也不能单独证明存在代码复用。因此，本补充不将当前项目直接标记为上游的衍生作品，不认定现有实现遗漏了必须附带的声明。

## 复用时的要求

如实际复制、移植或改编上游代码，或分发含有上游软件实质性部分的产物：

1. 保留上游完整的版权与 MIT 许可声明，包括免责声明；不要仅用 README 中的来源链接代替。
2. 在仓库记录所用上游版本和具体复用文件或模块，并让相关代码能找到其许可文本。
3. 在含有这些材料的源码包和应用分发产物中携带完整声明。Web 构建可将声明放入会随构建复制的第三方许可文件；原生应用可放入资源或随包的第三方许可目录。具体位置以实际打包方式为准。
4. README 中区分“参考过该项目”和“使用了哪些上游代码”，不要在未确认时写成整项移植。
5. 对其他依赖、图标、字体及素材分别核查许可；上游的 MIT 不能替代它们自己的许可。

如果核实只是参考功能或设计思路，且没有使用需保留声明的上游材料，则记录这一结论，不应为了署名而误标本项目代码来源或许可证。

## 发布验收清单

以下为待核验事项，不表示本次已经完成构建或分发合规验收：

- [ ] 核实是否使用上游材料；如有，记录版本、范围和来源。
- [ ] 如上游声明适用，确认仓库中的声明文本完整无删改。
- [ ] 如上游声明适用，检查实际构建产物、下载包及发布后的文件，确认声明随对应材料分发；不能只检查源码目录。
- [ ] 核查其他依赖和素材的许可证及通知要求。
- [ ] 由项目维护者单独决定本项目自身代码的开源许可证，不将第三方声明误当成本项目许可证。
